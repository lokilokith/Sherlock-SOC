# SHERLOCK Demonstration Script

1. Import the sample Sysmon JSON and show normalization.
2. Open Security Alerts and select the deterministic SOC-001 alert.
3. Show the matched indicators and source-event evidence references.
4. Sign in as an analyst before starting an investigation.
5. Start the investigation and show Triage, Forensics, and Threat Intelligence status.
6. Explain that deterministic detection ends at alert creation; agents interpret only supplied evidence.
7. Open the investigation workspace and show separate detection strength, evidence completeness, threat assessment, and execution status.
8. Point out unknown intelligence and missing evidence instead of presenting it as malicious certainty.
9. Finish with the consolidated findings, evidence tags, and recommended next steps.

The demonstration uses synthetic telemetry and demo providers unless live mode has been explicitly configured and independently validated.
